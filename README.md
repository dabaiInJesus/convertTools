# convertTools 🌍

> All-in-One File Format Converter — Free, Fast & Private

**Live:** [https://dabaiInJesus.github.io/convertTools/](https://dabaiInJesus.github.io/convertTools/)

## ✨ Features

- 🔄 **CSV ↔ JSON** — Convert CSV files to JSON and vice versa with proper escaping
- 📊 **Excel ↔ JSON** — Excel (.xlsx/.xls) to JSON conversion with full data support
- 📁 **CSV ↔ Excel** — Switch between CSV and Excel formats seamlessly
- 🔀 **JSON ↔ XML** — Convert between JSON and XML formats
- 📂 **Batch Convert** — Convert multiple files at once with ZIP download (Pro)
- 🔤 **Text Tools** — Base64 encode/decode, URL encode/decode, plain text
- 📋 **Conversion History** — Track your recent conversions with quick reload
- 📈 **Progress Indicator** — Visual progress bar for conversions
- 📱 **Responsive Design** — Works perfectly on desktop and mobile devices
- 🔒 **100% Browser-based** — No server upload, your files stay private
- 🚀 **Fast & Free** — No limits, no signup, no ads
- 💾 **Smart File Handling** — Proper CSV parsing with quote support

## 🛠️ Tech Stack

- Vue 3 (Composition API with TypeScript)
- Tailwind CSS for responsive design
- Vite for fast development
- SheetJS (xlsx) for Excel parsing
- JSZip for batch ZIP downloads

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Development server
npm run dev

# Build for production
npm run build

# Preview build
npm run preview
```

## 📦 Deploy to GitHub Pages

```bash
npm run deploy
```
